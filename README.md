The main objective is to demonstrate practical Excel skills through a structured, business-oriented analytics project.

A well-organized Excel workbook that demonstrates how spreadsheet tools can support data exploration, reporting, and business decision-making.

### 05 — Filter

**Purpose:** Retrieve specific records dynamically instead of manually searching the source table.

This worksheet demonstrates Excel's dynamic-array filtering capabilities.

**Example formula:**

```excel
=FILTER(tblTransactions,tblTransactions[Region]="West","No records found")
```

**Formula explanation:**

- `tblTransactions` — the complete source table to return.
- `tblTransactions[Region]="West"` — the condition that selects West-region records.
- `"No records found"` — the message displayed when no matching records exist.

The formula returns all columns for every row matching the condition. The results spill into the adjacent cells automatically.

**Business value:** Makes it easier to retrieve region-specific or condition-specific transaction records.

## 📈 09. Statistical Analysis and Forecasting

The Regression worksheet introduces statistical analysis using selected business variables.

### Regression Analysis

Regression can be used to examine how a dependent variable relates to one or more independent variables.

Examples of concepts included in a regression report:

- **R-squared:** Describes the proportion of variation in the dependent variable explained by the fitted model.
- **Adjusted R-squared:** Adjusts the model-fit measure for the number of predictors and sample size.
- **Coefficients:** Describe estimated changes associated with the predictors under the model.
- **Scatter Chart:** Helps visualize the relationship between two numerical variables.

### Forecasting

The forecast section demonstrates how a model or formula can be used to estimate future values.

Forecast results should be interpreted carefully. They are estimates, not guarantees, and should be evaluated against historical data, assumptions, and the business context.

## 🔬 10. What-If Analysis

What-If Analysis helps users explore hypothetical situations by changing input values and observing the resulting calculations.

### Techniques Demonstrated

- Scenario comparison.
- Sensitivity tables.
- Changing assumptions.
- Goal Seek setup.
- Reviewing calculated outcomes.

### Goal Seek Workflow

1. Prepare a formula that calculates the target result.
2. Identify the input cell that should change.
3. Open **Data → What-If Analysis → Goal Seek**.
4. Set the formula cell as the target.
5. Enter the desired target value.
6. Select the input cell to change.
7. Run Goal Seek and review the result.

**Important:** The output depends on the formula and assumptions in the workbook. Scenario results should not be treated as actual business outcomes.
